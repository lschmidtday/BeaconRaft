# BeaconRaft

BeaconRaft is an event-driven, fault-tolerant platform that enables real-time data processing through auto-scaling engines.

BeaconRaft is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- BeaconRaft is an event-driven, fault-tolerant

- processing through auto-scaling engines

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/BeaconRaft.git`
2. `cd BeaconRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

BeaconRaft is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
